# 记忆排序离线影子评估

## 范围

基线为 dev `82bc9b2`。本轮只增加测试与报告，不接入线上检索、提示组装或保留期决策，不修改 90/180 天清理规则，也不启用热冷分层。排序实验不赋予来源权限；先由真实 episode reader 取得可访问候选，再对同一候选集合重排。

任务类别参考 [LongMemEval 官方说明](https://github.com/xiaowu0162/LongMemEval/blob/main/README.md) 的信息抽取、多会话、知识更新、时间推理和拒答。本轮使用自建合成语料，不是 LongMemEval 测试结果；没有下载其数据、使用真实用户历史、请求外部模型或调用付费裁判。

## 预先固定的假设

实验分数为精确检索词命中数，加上最多 0.20 的时间项与最多 0.20 的有效读取证据项。时间半衰期为 30 天；这些数值只是此次实验的固定参数，不代表产品默认值或经过拟合的最佳参数。两个附加项之和小于一次完整命中差，防止仅靠新鲜度或频繁读取压过更强的词面匹配。词面匹配不等于语义相关性。

读取证据仅说明工具读取过某版本，不证明事实正确、模型引用、用户认可或仍然适用于当前问题。重放不新增证据，已退出证据窗口的调用不重新计入；候选曝光不能成为读取奖励。旧数据缺少证据不等于没有价值。

基线使用真实 reader 的现行排序，而不是替它实现一个近似排序。所有实验使用同一权限过滤候选池，因此只检验池内重排，不将扩大召回池的收益归入排序改进。池外漏检、同义词匹配缺失与有限扫描预算不能靠重排修复。

## 解读边界

召回与排名衡量的是预标注依据是否进入前若干条，不是答案正确率。来源指标衡量是否返回受限来源，不等于原文陈述真实；提供多个依据也不证明模型完成多会话推理。时间新旧不能代替问题指定的历史时点，读取频率也不能解决矛盾事实或更新关系。错误且频繁读取的旧记录可能被额外加分，必须保留这类反例。

字符数与评分候选数是确定性的上下文/计算代理指标，不是 tokens、费用或生产延迟。没有生成答案，因此错误引用率、真实模型任务成功率和付费模型成本均未测。合成用例数量小且由实现者设计，不能证明真实分布上的收益；不能仅凭平均值提升启用线上衰减。

## 固定评测结果

`synthetic-shadow-v1` 包含 13 条合成摘要、7 个问题，其中 5 个有可检索依据、2 个无答案。每个问题最多取 10 个已授权候选，比较前 2 条。两次完整运行结果一致。真实 SDK 调用读取旧预算摘要并获得 recorded 回执，相同调用重放为 replayed；排序完成后用明确标注的 257 次模拟历史推进退役水位，再验证原调用为 outside_window。另两个多事实读取信号是合成注入，不是用户真实使用数据。

| 方案 | 平均 Recall@2 | MRR@2 | 摘要字符合计 | 受限来源返回 |
| --- | ---: | ---: | ---: | ---: |
| 现行 SQL 顺序 | 0.90 | 0.70 | 174 | 0 |
| 词面 + 时间 + 读取 | 0.80 | 0.70 | 170 | 0 |
| 去掉时间项 | 0.80 | 0.70 | 170 | 0 |
| 去掉读取项 | 0.90 | 0.70 | 174 | 0 |
| 仅词面匹配 | 0.90 | 0.70 | 174 | 0 |

召回和 MRR 的分母为 5 个可答问题；字符数及来源错误累计全部 7 题。各变体在全部问题合计评分 13 个已授权候选次（跨问题可能重复）、进行 20 次检索词检查；共享池查询扫描 15 个候选次，包括过滤掉的来源。比较小池与共享池需要额外发起独立测试查询，这不是线上运行成本。字符少了 4 个不能称为模型成本降低。

- 多事实任务：读取奖励将两条相关事实提前，Recall@2 从 0.5 到 1。
- 更新冲突任务：旧预算有真实读取记录，奖励使其挤掉新决定，Recall@2 从 1 到 0。这是本轮明确的退化，不通过重新调权重隐藏。
- 旧重要记录：更强词面匹配保持第一，属于保留能力，不是新增收益。
- 历史时点任务：近期但不对应问题月份的事实仍排第一，目标依据 RR@2 为 0.5；新鲜度没有解决时点理解。
- 无答案但词面命中的问题仍返回候选，不能据此声称拒答成功。没有答案生成阶段，不计算拒答准确率。

**结论：不启用线上时间衰减或读取奖励。** 当前方案没有净收益，且已出现旧事实覆盖新决定的反例。下一步应先扩充独立标注的知识更新与历史时点任务、明确冲突依据的有效时间/替代关系，再在保持权限边界的离线实验中验证；不把规则关键词匹配伪装成语义判断。若随后需要真实模型端到端评测，应另行明确数据范围与费用，再测答案正确性、错误引用和实际 tokens。
