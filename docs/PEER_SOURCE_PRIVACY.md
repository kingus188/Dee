# 跨端资料功能的私人来源前置

本轮只修现有协作任务的私人来源准入与结果出口，不开启跨端资料检索。`search_local_knowledge` / `read_local_knowledge` 仍不在跨端授权名单内；本机选择资料目录不等于允许把内容发送到服务器。

## 已有能力的收口

真实服务器注入宿主的私人会话准入策略，复用记忆原文访问规则，在事务中读取当前Index和Wechat绑定。发起桌面任务、读取源authority及结果出口重新检查来源；归档、移除、绑定外部渠道或来源撤销后不能继续获得新的私有结果。root、内部/未登记子会话不是已授权私人会话，不通过猜测owner补权。无该宿主策略的底层通用runtime与桌面原有兼容行为不代表服务器已经批准访问。

`peer_task_status` 先核对原sourceSession及当前私有受众，再执行已有任务恢复或读取结果，并在异步等待之后复核。正常私人来源可以读取已完成的旧结果；15分钟源grant期限约束远端执行，不冒充历史结果读取权限。

取消仍可由原来源请求，不能把取消权限变成读取结果权限。私有准入失效时只返回取消请求的真实最小回执，不返回完整任务正文；取消请求不等于执行已终止。委派重放等返回完整任务的出口也须重新核验受众。会话目录及读取工具校验调用方；本节点Pi原文还要求目标是当前可读的私人会话，不能借内部或外部渠道会话绕过结果出口。

服务器自动续跑只发送任务ID、完成状态及固定读取提示，不把自由文本任务或结果正文写入续跑input。这样准入检查与SDK提交之间的非原子窗口不会注入私有结果；正文必须再经受控status读取。`resultDelivered` 仅表示续跑通知被SDK受理，不代表结果已读取、业务接受或已发送给外部人。已经受理的旧版本正文、已读工具结果不因本轮检查自动撤回。

## 仍未解决的设备身份与回传授权

现peer API的deviceId只是路由，在线状态由轮询自报；共享配对token或全局密码不能认证唯一设备。不能以本轮的用户输入锚点/私人会话策略宣称已经建立多用户或逐设备身份体系。本轮收紧模型工具与续跑投递，不把既有管理API的共享认证改称逐设备隔离，也不声称解决持有共享凭据者的冒用问题。

可信跨设备资料请求仍需：owner明确批准的短期单次配对；服务端分配设备身份和独立凭据摘要/版本；HTTP与WS统一的设备principal及逐路由校验；撤销现有连接、在途请求和恢复授权；任务、查询、目录及其授权代次、接收服务器和返回内容范围的单次批准。旧共享token不能静默升级。

当前authority通过规范HTTPS服务器核验，但普通结果complete可经已选择的LAN HTTPS WebSocket传输。未来资料任务的获取与回传都须固定同一可信目的地，不能只保护authority请求。现有设备凭据加密保存能力可复用，但尚无完整安全注册/撤销流程；它也不是防克隆的硬件身份。

## 验收范围

测试使用真实Durable SDK、Index/Wechat状态及SQLite撤销账本，传输由测试替身提供，不代表真实两台设备、生产账户或网络链路已经完成验收。本机资料UI仍未获得可用浏览器页面：受支持浏览器路径访问本地预览返回连接失败，未换端口、代理或工具绕过；真实Electron目录选择器与布局未验收。

本轮验证：`npm run check` 通过 TypeScript 与 7 个工作区、400 个源码模块的依赖边界检查；使用临时 PostgreSQL/pgvector 与 xsltproc 环境的全量 `npm test` 为 1501/1501 通过、无跳过。最终仅补测试覆盖后，服务器专项 7/7、runtime 来源授权专项 8/8 通过并重新编译；没有再次宣称执行全量。新增边界包括设备状态等待期间撤销来源，以及执行 grant 明确过期后的合法终态读取不重新授权执行。独立静态复核未发现本轮范围内阻塞。临时数据库运行目录已清理；未提交、推送或部署。
