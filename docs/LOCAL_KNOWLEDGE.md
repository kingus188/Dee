# 本机资料检索

## 使用与边界

本机 Pi 的“执行位置与 Agent 能力”区域可选择独立资料目录，默认未开启。选择工作目录不会开启资料检索。原生目录选择后需确认：检索与读取的片段会进入当前模型会话，使用云模型时会发送给相应模型提供商；不会自动上传整个目录或保存为长期记忆。清除目录阻止后续读取，不撤回已经进入会话或模型服务的内容。

新增 `search_local_knowledge` 与 `read_local_knowledge` 仅用于用户所选目录中的 Markdown / UTF-8 文本。既有 Pi 的逐项确认设置仍适用。此设置不改变已有编码工具或原生 Agent 的权限，不是整个客户端的操作系统沙箱。其他原生 Agent 不获得本功能，跨节点只读工具名单不扩展。

## 检索与引用

搜索复用既有关键词、分词和有限同义词规则，不要求知道文件名；不是向量语义搜索，也不能保证所有相关资料都被找到。按请求扫描，不建立后台索引，不写原文缓存或长期记忆。返回路径、起止行号、内容版本、片段及截断信息。扫描和返回结果有上限，未命中、不支持的格式、访问失败以及达到预算必须区分；不能把不完整扫描说成“没有资料”。

按版本读取使用检索返回的相对路径、版本与行号。版本包含原始文件字节散列、规范化目录和目录授权代次；文件修改、清除或更换目录后不能将新内容当旧引用返回。修改时间不作为事实生效时间，版本匹配也不证明内容为真。读取返回观察到的版本，不承诺响应瞬间全局最新或完整历史。

## 隐私与失效

拒绝路径穿越、符号链接和隐藏/敏感目录，使用现有敏感凭据检测拒绝已识别内容。检测不是完整的数据分类器，不保证识别所有秘密。输入与输出都限制大小；资料正文只作证据，其中的指令不能扩大权限。目录授权在等待确认及读取后复核，撤回再选回同一目录也会产生新代次，旧请求不能继续。

文件系统检查不等于防御恶意并发文件系统修改的OS沙箱。PDF、Office、图片、二进制及超过支持大小的文件本阶段不解析；长文本截断标记不代表已读全文。没有新增服务器同步或记忆摄入，也未改变90/180天保留规则。

## 当前预算

每次搜索最多检查2000个目录项、尝试200个支持类型文件，每个文件最多256KiB；因此最大文件读取量约50MiB，不承诺磁盘/网络文件系统的墙钟超时。返回前5个候选，每个预览最多8行/1200字符；按版本读取沿用6200字符片段上限。`scan` 报告达到预算、跳过、不支持、敏感凭据拒绝与不可访问计数。有相关候选也可能是 `partial`，不能当成完整搜索。

## 依赖与构建

Desktop显式依赖已有 `@assistant/features`，复用知识匹配、分行、状态分类及敏感检测；没有注册其服务器业务扩展。架构允许 `desktop → features → runtime/contracts`，仍禁止跨包相对导入、未声明依赖、循环及客户端访问服务器适配器；其余依赖边界检查保持不变。没有新增外部依赖或升级锁定版本。

使用与 `scripts/desktop-package.ts` 相同的esbuild主进程打包参数进行了等价构建，完整解析1425个输入模块，未引入 `apps/server` 或微信服务端通道模块，外部导入仅Electron与Node内置模块。这不是完整平台安装包、签名或实际Electron启动验收。
